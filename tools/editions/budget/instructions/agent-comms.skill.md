# Agent Comms Skill

Use this only for internal agent-to-agent summaries and long tool-result condensation in Budget edition.

- Keep routine internal returns to 200-300 tokens.
- Prefer terse bullets, small tables, or YAML envelopes.
- Preserve exact filenames, commands, test results, error text, risks, and decisions.
- Do not compress README content, stories, release notes, PR descriptions, formal architecture docs, or other user-facing artifacts into terse shorthand.
- If compression would hide evidence needed for a decision, keep the evidence and shorten surrounding prose.
