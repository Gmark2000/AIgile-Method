# Roadmap

This roadmap outlines near-term priorities for the AIgile Development Method. It is intentionally lightweight and subject to change.

## Near term (0–1 releases)
- Enrich remaining agent docs (Analyst, Architect, PM, SM, UX/UI) with personas and concrete commands
- Add role-focused bundles (qa-agent-bundle.txt, po-agent-bundle.txt) and a `dist/manifest.json`
- Finalize stack-agnostic pass across tasks and templates
- Add basic automated checks for CLI (lint, minimal smoke tests)

## Mid term (1–3 releases)
- Optional: sample MCP server docker-compose for local demos
- Optional: add test harness for task examples (linting and link checks)
- Improve docs with short how-tos per role

## Long term
- Community task library contributions and curation
- Additional expansion packs via separate packages
